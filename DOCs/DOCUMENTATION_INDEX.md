## 🚀 Getting Started with Code

After reading documentation:

1. **Local Setup** (5 min)
   ```bash
   git clone https://github.com/ZeroTrace0245/inventory-Managment.git
   cd inventory-Managment
   dotnet run
   # Access: http://localhost:5018
   # Login: demo / demo123
   ```

2. **Explore the Code**
   - Check: `Program.cs` (entry point)
   - Check: `Inventory/` folder (services)
   - Check: `Components/` folder (UI pages)

3. **Try the Features**
   - Add a product: `/products`
   - Adjust stock: `/stock`
   - Check AI: `/labs` (needs GitHub token)
   - Explore: Dashboard `/`

4. **Next Steps**
   - Add unit tests
   - Migrate to database
   - Deploy to cloud
   - Add mobile app
